## Checks on the additions

The batched profile optimizer was compared with 200 scalar fits, with a maximum parameter difference about 5.3e-8. Its specimen-conservation checks cover heterogeneous designs. The fast generator's retained-count mean is compared with the original complete-lifetime generator. The independent MCMC checks agree with quadrature within about 2.2 sampler MCSEs at worst among the tested means.

The primary data were not selected by testing many gauge pairs. The two endpoint gauge groups were specified before fitting. Source Excel checksums match the authors' published Zenodo checksums. All 153 valid specimen rows in each selected workbook were retained, including the low measured strengths. There was no filtering to improve the Weibull tests. The published article describes approximately 150 fibres per length; this project reports its exact extracted workbook counts instead of copying an approximate article count.

The workbook order did not yield six upper 2-records. The new retained-data illustration therefore uses one fixed seeded permutation, not a search for a favourable result. It remains a retrospective acquisition design. The complete-data nonparametric calculation does not depend on that ordering.

None of these changes makes an observational result an operating-load reliability certificate, makes an approximate interval exact, or proves a distribution from a non-rejection. Those limits are part of the final report.
