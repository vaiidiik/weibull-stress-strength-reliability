\subsubsection{Simulation algorithms}\label{sec:generation}
Strength lifetimes are generated completely, but only observed failures and censoring information enter estimation. Withdrawn lifetimes are hidden. For stress records, independent unit-mean exponential variables give
\begin{equation}
y_j=\left(\frac{\sum_{l=1}^{j}E_l}{kb}\right)^{1/\alpha},\qquad j=1,\ldots,r.\label{eq:record-generation}
\end{equation}
This generates the marginal record values directly, without waiting times. Published-data examples instead scan their stated acquisition sequence.

\begin{algorithm}[htbp]
\caption{Generate one retained dataset}\label{alg:data}
\begin{algorithmic}[1]
\REQUIRE $(\alpha,a,b)$, block designs, protocol, $k$ and $r$
\FOR{each strength block $i$}
\STATE Generate $n_i$ lifetimes using \eqref{eq:quantile}; mark them active
\WHILE{fewer than $m_i$ failures have been observed}
\STATE Find the next active failure
\IF{Type I and the next failure exceeds $T_i$}
\STATE Censor active survivors at $T_i$ and stop the block
\ELSE
\STATE Record the failure and remove that specimen
\STATE Withdraw uniformly selected survivors using the planned count
\STATE For adaptive Type II, use zero planned withdrawals after $T_i$
\STATE At the target failure, withdraw all survivors and stop the block
\ENDIF
\ENDWHILE
\STATE Save failures, actual withdrawals and terminal survivors
\ENDFOR
\STATE Generate $r$ stress records using \eqref{eq:record-generation}
\STATE Check specimen conservation and return only retained observations
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[htbp]
\caption{Compare the four estimators}\label{alg:simulation}
\begin{algorithmic}[1]
\REQUIRE Forty-eight settings, $M=1000$, fixed prior and seed
\FOR{each setting and replication}
\STATE Generate one dataset by Algorithm~\ref{alg:data}
\STATE Form $A(\alpha),B(\alpha),C,d,r$ from the retained data
\STATE Maximize both profiles, including order-boundary pooling
\STATE Integrate \eqref{eq:collapsed} on each posterior support
\STATE Save means, equal-tail and numerical HPD intervals
\STATE Save the unrestricted log-ratio ACI and error against the fixed truth
\ENDFOR
\STATE Summarize bias, MSE, coverage, width and their Monte Carlo errors
\STATE Assess bootstrap coverage separately in twelve selected settings
\end{algorithmic}
\end{algorithm}

Posterior integration includes the log-shape Jacobian and quadrature weights. Conditional Gamma means recover the two rate means after integrating out $t$. The reliability marginal gives equal-tail intervals; transforming its density and finding the shortest 0.95 interval gives the numerical HPD approximation. Finer grids check both calculations. A pooled ordered MLE receives no invented regular-normal interval. Its bootstrap preserves the full observation scheme, as described in Section~\ref{sec:extra-bootstrap}.
